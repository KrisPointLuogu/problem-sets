# A. 求和

## 题目描述

记 $f(k)$（其中 $k$ 是正整数）表示所有 $2$ 的**正整数次幂数**中能被 $k$ 整除的最大的数，例如 $f(10^k)=2^k$。

给定 $n$，求

$$
\sum\limits_{i=n+1}^{2n}\dfrac{i}{f(i)}
$$

## 输入格式

仅一行一个整数 $n$。

## 输出格式

仅一行一个数，表示答案。

## 样例

### 输入样例 1

```
2
```

### 输出样例 1

```
4
```

### 样例 1 说明

$f(3)=1$，$f(4)=4$。

因此，$\dfrac{3}{f(3)}+\dfrac{4}{f(4)}=3+1=4$。

### 输入样例 2

```
77777
```

### 输出样例 2

```
6049261729
```

## 数据规模与约定

- 测试点 $1\sim3$：$n\le 10^3$。
- 测试点 $4\sim6$：$n\le 10^5$。
- 测试点 $7\sim10$：无特殊限制。

对于 $100\%$ 的数据：$1\le n\le 10^9$。

# B. 取模 2

## 题目描述

给定 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

再给定 $A$，你需要从数列 $a$ 中选择 $m$ 项，以任意顺序排列为 $b_1,b_2,\ldots,b_m$，使得 $(\ldots((A\bmod b_1)\bmod b_2)\bmod\ldots)\bmod b_m=0$。

求出 $m$ 的最小值。**若无解，请输出 `-1`。**

## 输入格式

**本题有多组数据。**

第一行一个整数 $T$，表示数据组数。

对于每组数据：

- 第一行两个整数 $n,A$，意义如题述。
- 第二行 $n$ 个数，表示 $a_1,a_2,\ldots,a_n$。

## 输出格式

对于每组数据，仅一行一个数，表示答案。

## 样例

### 输入样例 1

```
2
2 9
2 7
1 3
2
```

### 输出样例 1

```
2
-1
```

### 样例 1 说明

- 对于数据 1：考虑 $9\bmod 7=2$，$2\bmod 2=0$。可以证明，$2$ 是 $m$ 的最小值。
- 对于数据 2：显然无解。

## 数据规模与约定

| 测试点 | 限制 |
|:-:|:-:|
| $1$    | 存在 $i$ 使得 $a_i=1$ |
| $2\sim3$ | $2\le a_i\le 20$  |
| $4\sim5$    | $n\le10$ |
| $6\sim10$    | 无特殊限制 |

对于 $100\%$ 的数据，$1\le T\le 3$，$1\le n \le 20$，$1\le A,a_i\le 10^6$。

# C. 整除 2

## 题目描述

给定一个长度为 $n$ 的数列 $a$，你可以操作任意次，每次选择数列中相邻的两个元素 $u,v$，计算 $w=u+v$，并将 $w$ 插入 $u,v$ 之间，再把 $u,v$ 删除。

求出最终数列中最多能有多少项能被 $p$ 整除。

## 输入格式

第一行两个整数 $n,p$。

第二行共 $n$ 个数，表示数列 $a$。

## 输出格式

仅一行一个数，表示答案。

## 样例

### 输入样例 1

```
5 3
1 2 3 1 2
```

### 输出样例 1

```
3
```

### 样例 1 说明

两次均选定 $u=1,v=2$，操作后，数列 $a=[3,3,3]$。

## 数据规模与约定

- 数据点 $1$：$p=2$。
- 数据点 $2\sim3$：$n\le 10$。
- 数据点 $4\sim6$：$n\le 2\times10^3$。
- 数据点 $7\sim10$：无特殊限制。

对于 $100\%$ 的数据，有 $1\le n,p,a_i\le 10^6$。

# D. 差异

## 题目描述

对于两个长度相等的字符串 $s,t$，若 $s,t$ 不同的位数不超过 $k$，则称 $(s,t)$ **关系很好**。

现在给定长度为 $n$ 的字符串 $S$，对于每个 $1\le i\le n-1$，记字符串 $A$ 为 $S$ 的前 $i$ 位，$B$ 为 $S$ 的后 $n-i$ 位。

现在 $a,b$ 分别为 $A,B$ 的子串，求出有多少对 $(a,b)$ 关系很好。

## 输入格式

第一行两个整数 $n,k$，意义如题述。

第二行一个字符串 $S$。

## 输出格式

共 $n-1$ 行，每行一个整数，表示答案。

## 样例

### 输入样例 1

```
4 0
abca
```

### 输出样例 1

```
1
1
1
```

### 样例 1 说明

一直都有且仅有 $(\texttt a,\texttt a)$ **关系很好**。

### 输入样例 2

```
6 1
abcadd
```

### 输出样例 2

```
5
9
10
8
5
```

## 数据规模与约定

- 测试点 $1$：$S$ 仅由一种字符构成；
- 测试点 $2\sim 3$：$n\le 10$；
- 测试点 $4\sim 6$：$n\le 100$。
- 测试点 $7\sim 10$：无特殊限制。

对于所有数据，$2\le n\le 3\times 10^3$，$0\le k\le 3\times 10^3$。**且 $S$ 仅由小写字母构成。**
