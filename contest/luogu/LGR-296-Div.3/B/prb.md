问题本质：每轮删除"排名为完全立方数"的元素，过程只由排名决定，与数值无关。
一条递推就够：设 D[y] = 排名为 y 的元素还要几轮才被删（0 = 本轮删）。
- y 是立方数 → 本轮删：D[y] = 0
- 否则它前面被同时删掉的是"排名为立方数且 < y"的元素，共 C(y) 个（C(y) = 1..y 中立方数个数）。下一轮它排名变成 y - C(y)，所以：
D[y] = 1 + D[y - C(y)]
因为 y - C(y) < y，按 y=1→n 递增算一遍即可，O(n)。这正是"同时删除"的正确建模：排名变换 = 原排名 − 前面被删个数，而前面被删的恰好都是立方数排名。
你的"以 cube 为界分段"：立方数把 1..n 切成段 [k³, (k+1)³-1]，段内所有 y 满足 C(y) = k，于是段内递推退化成统一偏移：
- y = k³（段首立方数）→ 0
- 其余 → D[y] = 1 + D[y - k]（指针偏移 c = k）
输出：位置 p 在第 D[p]+1 轮删，按 D[p] 分桶、桶内 p 递增即原顺序。
